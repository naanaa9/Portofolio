# Diana Kusumaningsih - Portfolio

Portfolio website pribadi yang menampilkan proyek, skill, dan informasi kontak.

## 🚀 Fitur

- ✅ Responsive design untuk mobile, tablet, dan desktop
- ✅ PWA (Progressive Web App) support untuk Android
- ✅ Modern UI dengan Tailwind CSS
- ✅ Smooth scrolling navigation
- ✅ Dark/Light mode ready
- ✅ Fast loading dengan Vite

## 🛠️ Teknologi

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Radix UI Components
- Lucide Icons

## 📱 Kompatibilitas

Website ini dioptimalkan untuk:
- ✅ Android (Chrome, Firefox, Samsung Internet)
- ✅ iOS (Safari, Chrome)
- ✅ Desktop (Chrome, Firefox, Safari, Edge)
- ✅ Tablet devices

## 🏃‍♂️ Cara Menjalankan

### Development
```bash
npm install
npm run dev
```

### Build untuk Production
```bash
npm run build
```

## 📂 Struktur Project

```
├── public/              # Static assets
├── src/
│   ├── components/      # React components
│   │   ├── ui/         # Reusable UI components
│   │   └── ...         # Page components
│   ├── styles/         # Global styles
│   ├── App.tsx         # Main app component
│   └── main.tsx        # Entry point
├── index.html          # HTML template
└── vite.config.ts      # Vite configuration
```

## 🎨 Customization

Untuk mengubah warna tema, edit file `src/styles/globals.css`:
```css
:root {
  --primary: #030213;
  --background: #ffffff;
  /* ... */
}
```
